## Repository Instructions & Critical Rules

### Event Banners & Posters Rule (STRICT MANDATORY REQUIREMENT)
- **MUST KEEP 2 BANNERS FOR EVERY EVENT: 1:1 AND 16:9**
  1. **16:9 Landscape Banner (`banner_url`)**:
     - **Aspect Ratio**: `16:9`
     - **Primary Surfaces**: Explore Page Featured Hero, Event Page Hero / Ambient Header, wide desktop banners.
  2. **1:1 Square Banner (`square_banner_url`)**:
     - **Aspect Ratio**: `1:1` Square
     - **Primary Surfaces**: Timeline event cards, list thumbnails, mobile feed cards, compact event previews.

- **Requirements**:
  - Always maintain both `banner_url` and `square_banner_url` across all schemas, APIs, UI editors, and display components.
  - Never discard or conflate the two ratios into a single image.
